# Old-School Essentials Reforged Rules

*House rules for Old-School Essentials and classic B/X that keep lethal exploration intact while filling the gaps long campaigns actually hit.*

_Old-School Essentials Reforged_ is a house-rule framework by Apostol Apostolov for _Old-School Essentials_ (OSE) and classic B/X D&D. It sits on top of the published Advanced Fantasy books. It does not replace them wholesale. The bias is sharper structure, deeper character options, and subsystems that hold up under months of play — without turning B/X into a modern game.

You need the published OSE rules to use this. The framework targets a 14-level game with accelerated XP (×10 standard progression) so advancement fits a modern play schedule.

## What’s New in 2.0.1

## Highlights

Ordered the way the rules chapters read. These are the systems this edition built out hard.

- **Unified Class Rework.** Basic, demihuman, and advanced classes get targeted fixes instead of one-size patches. Demihumans carry higher ability gates and stronger racial features; advanced classes gain abilities worth picking. Three THAC0 groups (Warrior, Adventurer, Mage) replace per-class attack tables through level 14.

- **Expanded Combat Procedures.** Slow-weapon death delay, subduing damage, parry and riposte, covering an ally, shooting past creatures, withdraw, ganging up in melee, and fire or bleeding damage give the fight more levers without a new edition’s action economy. Masterwork gear sits beside magic so fine craft matters before +1 swords appear.

- **Expanded Skill System.** Forty-plus skills organized by attribute, with starting slots from Intelligence and gains across the career. Checks scale Simple / Expert / Heroic, and class-feature protection stops a general skill from eating a class’s signature job.

- **Weapon Mastery and Unarmed Tracks.** Ranks from Basic through Grand Master, with slot progression by class group, teachers, costs, and quest gates. Brawling, Wrestling, and Martial Arts each spend their own slots; the Wrestling subsystem turns grappling into a full close-combat game when you want that depth.

- **Hireling Rules.** Separate XP pools, clearer limits, and Level 0 play so retainers are a campaign resource instead of nameless meat.

- **Environment and Vision.** Darkness, infravision, low-light, and moonlit vision sit with torch types and durations so dungeon lighting is a procedure, not a shrug.

- **XP and Downtime.** Philanthropy with social fallout, carousing by venue tier, life XP, and spell-learning rewards give gold somewhere useful to go between expeditions.

- **New Classes.** The Sage (and further additions in Additional Content) extend the Advanced Fantasy roster with Reforged-native options.

## The books

There is no single “corebook PDF” here — the rules live as Markdown chapters meant for table reference and clean diffs.

- **Rules** (`rules/`) — Character Creation through XP and Downtime, in reading order.
- **Additional Content** — New classes such as the Sage.
- **Subsystems** — Optional depth (Wrestling).
- **Appendix** — Ability score descriptors; feudal Slavic torch realism.
- **Analysis** — [Class Power Level Analysis](analysis/class-power-analysis.md) for DMs and optimizers (reference tool, not rules text).

## What This Is Not

- Not a replacement for the published OSE Advanced Fantasy books
- Not an official Necrotic Gnome product or endorsement
- Not a Foundry VTT package (see the family table for the modules and character creator)

## How to use

1. Keep OSE Advanced Fantasy as the base; apply Reforged on top.
2. Read the rules chapters in order; each builds on the last.
3. Treat Weapon Mastery and the skill system as the largest optional blocks — either can run alone.
4. Use the Class Power Level Analysis to understand tiers, not as mandatory balance law.
